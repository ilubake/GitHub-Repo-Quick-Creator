# GitHub-Repo-Quick-Creator
Windows batch script to simplify GitHub repo creation &amp; local cloning (bilingual support). Auto-checks Git/GitHub CLI/login status, one-click creates &amp; clones private repo via input name—no manual web/repo init steps. （Windows 批处理脚本，简化 GitHub 仓库创建与本地克隆（双语支持），自动检测 Git/GitHub CLI / 登录状态，输入名称一键创建并克隆私有仓库，无需手动网页操作 / 仓库初始化。）
